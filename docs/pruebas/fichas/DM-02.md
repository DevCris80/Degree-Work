# DM-02 — Destino de un código escaneado

| Campo | Contenido |
|---|---|
| Requisitos | RF-16, RF-17 |
| Escenario | — |
| Verificación automática relacionada | `ResolverDestinoEscaneoTest`, `EscanearViewModelTest`. |
| Dispositivo | Samsung Galaxy A15 (SM-A155M) |
| Cómo se ejecuta | Manual, con el código digitado: no hace falta chapeta física (RNF-06). |
| Estado | Pendiente de ejecutar |

## Preparación

- Sesión iniciada.
- Cuatro códigos: (a) chapeta activa de un animal activo; (b) chapeta activa de un animal dado de baja; (c) chapeta liberada de un animal que tuvo ese código; (d) un código que la app nunca vio.

## Pasos

1. En Escanear, ingresar el código (a).
2. Volver y repetir con (b), (c) y (d).
3. Grabar la pantalla.

## Resultado esperado

- (a) abre el detalle del animal.
- (b) pide liberar la chapeta primero y nombra al animal dado de baja.
- (c) abre el registro de un animal nuevo avisando del animal anterior.
- (d) abre el registro de un animal nuevo con el código puesto.

## Criterio de aprobación

Los cuatro códigos llevan a su destino.
