# DM-01 — Lectura del UID de una chapeta NFC

| Campo | Contenido |
|---|---|
| Requisitos | RF-15 |
| Escenario | — |
| Verificación automática relacionada | `EscanearViewModelTest`, `ResolverDestinoEscaneoTest` (la normalización del código). Ninguna prueba automatizada toca el lector NFC. |
| Dispositivo | Samsung Galaxy A15 (SM-A155M). El A15 declara la función NFC (`android.hardware.nfc`); si el Oppo se usa también, se repite allí. |
| Cómo se ejecuta | Manual: necesita una chapeta física. |
| Estado | Pendiente de ejecutar |

## Preparación

- NFC activado en Ajustes del celular.
- App con la sesión iniciada.
- Dos chapetas NTAG215 (NFC-A) con su UID leído antes con otra app de NFC, como referencia.

## Pasos

1. Abrir Escanear.
2. Acercar la primera chapeta a la parte trasera del celular.
3. Anotar el código que muestra la app.
4. Repetir con las otra chapeta.
5. Grabar la pantalla durante las dos lecturas.

## Resultado esperado

- La app muestra el UID en mayúsculas y sin `:`, `-` ni espacios (RN-02).
- Es el mismo UID de la referencia, sin los separadores.

## Criterio de aprobación

Los dos códigos leídos coinciden con la referencia.

## Evidencia

- Video de las dos lecturas.
- Captura de la app de referencia con cada UID.
