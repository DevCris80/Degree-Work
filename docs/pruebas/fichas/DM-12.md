# DM-12 — Tiempo hasta que un pesaje es visible

| Campo | Contenido |
|---|---|

| Escenario | DE-01 |
| Verificación automática relacionada | Ninguna. |
| Dispositivo | Samsung Galaxy A15 (SM-A155M) |
| Cómo se ejecuta | Script `dm12-tiempo-de-pesaje.sh` con la pantalla grabada con `adb shell screenrecord`. |
| Estado | Pendiente de ejecutar |

## Preparación

- App de prueba con sesión iniciada y servicio de pesaje activo.
- Un animal activo con chapeta; su detalle abierto en pantalla.
- Grabación de pantalla en marcha.

## Pasos

1. Correr `dm12-tiempo-de-pesaje.sh <codigo> 30 3`.
2. Con el video, ubicar cada hora de envío de `tiempos.csv` y anotar el instante en que aparece el pesaje.
3. Calcular el tiempo de cada uno de los 30.

## Resultado esperado

- Cada pesaje es visible en el detalle abierto en 5 s o menos.

## Criterio de aprobación

Los 30 pesajes ≤ 5 s (RNF-05). La respuesta HTTP del script es solo una cota inferior.

## Evidencia

- `tiempos.csv` y `resumen.txt`.
- El video con los instantes anotados.
