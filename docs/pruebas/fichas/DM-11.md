## Preparación

- App de prueba (`.prueba`) con sesión iniciada y servicio de pesaje activo.
- Celular y máquina en el mismo wifi.

## Pasos

1. Correr `dm11-una-sola-vez.sh 50 2` (50 pesajes, cada uno repetido dos veces con el mismo `id_lectura`).
2. Repetir con el código de una chapeta activa para cubrir el caso 201.
3. Revisar `resultados/dm11-*/resumen.txt`.

## Resultado esperado

- Cada reintento recibe la misma respuesta que el envío original.
- La base tiene exactamente 50 filas, una por `id_lectura`.

## Criterio de aprobación

Guardados = enviados, sin repetidos, en las dos corridas.

## Evidencia

- `resumen.txt` y `envios.log` de cada corrida.
