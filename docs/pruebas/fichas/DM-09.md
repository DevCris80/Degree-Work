# DM-09 — Funciones de registro y consulta en modo avión

| Campo | Contenido |
|---|---|
| Requisitos | RNF-01 |
| Escenario | — |
| Verificación automática relacionada | Ninguna: el diseño offline-first (ADR-0001) no tiene una prueba que apague la red. |
| Dispositivo | Samsung Galaxy A15 (SM-A155M) |
| Cómo se ejecuta | Manual con ayuda de `adb`: el modo avión se puede activar con `adb shell cmd connectivity airplane-mode enable`. |
| Estado | Pendiente de ejecutar |

## Preparación

- Sesión iniciada con señal antes de empezar (LIM-02).
- Datos de la finca ya descargados.
- Modo avión activado y el wifi apagado.
- Servicio de pesaje iniciado para las filas de RF-20 a RF-25.

## Pasos

1. Recorrer la lista de verificación de abajo en el orden que aparece.
2. En cada fila marcar si la función se pudo usar sin señal y anotar cualquier mensaje de error.
3. Grabar la pantalla durante todo el recorrido.

## Resultado esperado

- Ninguna función de la lista pide señal ni muestra un error de red.

## Criterio de aprobación

El 100 % de las filas marcadas (RNF-01). Quedan fuera por LIM-02: RF-01 a RF-03, RF-05, RF-07 y RF-32 a RF-38.
